# 文件目录与导航

文档的真实文件夹就是分类结构。中文与英文使用完全相同的相对路径，例如：

    i18n/zh-Hans/docusaurus-plugin-content-docs/current/controllers/SPIDER_V1-3_F446.md
    i18n/en/docusaurus-plugin-content-docs/current/controllers/SPIDER_V1-3_F446.md

当前有 15 个分类文件夹。产品与教程分类按 HelpLook 的层级组织，保留快速开始和补充资料分类。文档总览 overview.md 保留在根目录，其余文档进入对应分类。

- 新建或移动文章：直接操作文件夹，或使用 CMS 原生的“上级文件夹”。两个语言版本应一起移动，保持相对路径相同。
- 文章顺序：使用 frontmatter 的 sidebar_position。
- 2026-10-29 已按官网公开目录校齐文章顺序（排除 3D Printer Kits）。官网未列出的本地文章保留在对应分类末尾，语言重复条目按首次出现的位置合并。核对快照见 official-article-order-2026-10-29.json；运行 node scripts/sync-official-article-order.mjs --check 检查排序及排除目录是否保持不变。
- 目录名称、目录顺序、折叠状态、目录首页：使用该目录中的 _category_.json；新增目录没有此文件时，会显示文件夹名。
- 页面地址：已有文章保留绝对 slug，因此移动目录不改变访问地址。
- sidebars.js 使用 Docusaurus 的 autogenerated，自动识别文件夹和嵌套结构。
- catalog.json 是从真实文件夹派生的首页分类入口，不用于管理文章归属；不直接编辑。
- scripts/sync-navigation.mjs 只更新首页分类入口和中文分类翻译，不会移动文章或重建旧目录结构。

旧的 tree.json 和自定义目录管理逻辑已移除；official-categories.json 仅保留为历史参考。

运行 npm run test:navigation 和 npm run build 验证；npm run nav:sync 可单独刷新首页入口。CMS 本地模式选择 wiki.fysetc 仓库根目录。GitHub 模式只能看到已经提交并推送的文件，先本地审阅时请使用本地模式。

默认语言为英文，导航以 i18n/en 中的文件夹和分类配置为源，i18n/zh-Hans 提供中文翻译。英文 URL 位于根路径，中文加 /zh-Hans/ 前缀，已有文章 slug 保持不变。

HelpLook 本地导入说明、文章对应关系及源文件缺失资源见 [迁移记录](../migration/README.md)。带数字的 Venture XL 子目录保留原有编号，站点关闭自动去除数字前缀，以使文件夹路径与文档 ID 一致。
