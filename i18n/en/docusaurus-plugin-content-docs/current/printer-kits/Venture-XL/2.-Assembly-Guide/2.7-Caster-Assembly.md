# 2.7 Caster Assembly

![](/images/venture-xl-assembly-guide-caster-assembly--caster-assembly-01.png)

- Turn the machine over and install the caster fixing plate first；
- Then install the casters and tighten the screws；
- Install 4 casters in sequence；

![](/images/venture-xl-assembly-guide-caster-assembly--install-4-casters-in-sequence.png)

**<u>***NOTE: The caster can be stationary or rolling by adjusting the screw.***</u>**

![](/images/venture-xl-assembly-guide-caster-assembly--caster-assembly-02.png)
