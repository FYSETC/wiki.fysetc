# 2.7 脚轮组件

![](/images/venture-xl-assembly-guide-caster-assembly--caster-assembly-01.png)

- 将机器翻转过来，先安装脚轮固定板；
- 然后安装脚轮并拧紧螺丝；
- 依次安装4个脚轮；

![](/images/venture-xl-assembly-guide-caster-assembly--install-4-casters-in-sequence.png)

**<u>***注意：通过调节螺丝，脚轮可以固定或滚动。***</u>**
