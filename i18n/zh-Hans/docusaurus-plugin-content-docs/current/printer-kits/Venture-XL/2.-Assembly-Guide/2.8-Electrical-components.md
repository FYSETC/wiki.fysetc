# 2.8 电气组件

## 2.8.1 热床线固定
- 将热床加热器的四根零线（末端带压接端子的线）连接，并与将连接到电子设备外壳的蓝色零线一起插入螺丝端子母线；
- 并使用螺丝将接线端子固定到型材上；
- 热床电源线和电机线穿过红色框架上的孔；
- 参照接线图完成组装

![](/images/venture-xl-assembly-guide-electrical-components--hot-bed-line-fixed.png)
  
## 2.8.2 显示屏安装
- 显示屏已组装完成，需先取下后盖；
- 将灰色线缆的一端插入图中红色区域；
- 拧紧螺丝并将其居中安装到型材上；

  ![](/images/venture-xl-assembly-guide-electrical-components--display-installation.png)
 
### 显示屏线缆固定
- 在显示屏线缆的两端各安装一个磁环；
- 显示屏的灰色线缆沿型材固定。螺丝已拧紧；
- 显示屏灰色线缆的一端穿过绿色框架上的孔；

![](/images/venture-xl-assembly-guide-electrical-components--display-cable-fixing.png)

  **<u>***注意：注意线缆的穿线位置。***</u>**

## 2.8.3 电箱安装
- 撕掉亚克力板两侧的保护纸；

![](/images/venture-xl-assembly-guide-electrical-components--electric-box-installation.png)


### 电箱锁安装
- 按图示组装；
- 将把手和锁安装到电箱内部；
  
  ![](/images/venture-xl-assembly-guide-electrical-components--electric-box-lock-installation.png)

### 电箱固定
- 通过 6 颗 SHCS M3x8 将电箱固定到框架右侧；
- 将显示屏、电机、热床和 CAN 板线缆穿过窗口并连接到主板；
- 安装位置请参考接线图；

![](/images/venture-xl-assembly-guide-electrical-components--electric-box-fixing.png)

## 2.8.4 线缆接线
### 版本 1：Spider Pro
- 首先拆下风扇及其支架；
- 将显示屏、电机、热床和 CAN 板线缆插入主板；


:::note

电机接线序号参考。

:::


| 编号| 1| 2| 3|4 |5 |6 |
| - | - | - | - | - | - | - |
| 电机序号| Z0| Z1| Z2| Z3| A| B|
| 主板序号| M0| M1| M2| M3| M6| M7|

![](/images/venture-xl-assembly-guide-electrical-components--version-1-spider-pro-02.png)

- 需要将显示屏线缆上的导电胶带粘贴到网线端口的金属外壳上。

![](/images/venture-xl-assembly-guide-electrical-components--version-1-spider-pro-01.png)

 **<u>***注意：确保显示屏灰色线缆的两端各有一个磁环。这些是为了增强控制电路的抗干扰能力。***</u>**

- 首先拆下风扇及其支架；

:::note

:::


| 编号| 1| 2| 3|4 |5 |6 |
| - | - | - | - | - | - | - |

| 主板序号| M0T10-E4| M0T9-E3| M0T8-E2| M0T7-E1| M0T4-Z| M0T3-Y|
