# 2.5 挤出机头组件

![](/images/venture-xl-assembly-guide-extrusion-head-assembly--extrusion-head-assembly.png)

## 2.5.1 打印热熔螺母
- 使用电烙铁对打印件进行热熔焊接；

※打印件需要更新（Chain_Anchor_3_Hole_V2_TridentG）。

https://github.com/FYSETC/Venture_XL/tree/main/STLs

![](/images/venture-xl-assembly-guide-extrusion-head-assembly--printed-hot-melt-nut.png)


## 2.5.2 挤出机头套件组装
- 按图示进行组装；
- 步骤⑥需要将微动开关的引脚压平；
- 步骤⑧需要先将电机端子插入 SB CAN 板；
- 结合参考接线图完成组装；

![](/images/venture-xl-assembly-guide-extrusion-head-assembly--extrusion-head-kit-assembly-01.png)

- 按图示进行组装；
- 步骤③中的刀片需要压入。刀片必须锋利，并注意安全。；
- 结合参考接线图完成组装；

  ![](/images/venture-xl-assembly-guide-extrusion-head-assembly--extrusion-head-kit-assembly-02.png)



:::note

  ***注意：注意线缆的走线位置。***

:::


## 2.5.3 挤出机头套件安装

- 材料准备
  
- 按图示进行组装；
- 结合参考接线图完成组装

![](/images/venture-xl-assembly-guide-extrusion-head-assembly--extrusion-head-kit-installation-01.png)

- 注意 CAN 的安装位置。

![](/images/venture-xl-assembly-guide-extrusion-head-assembly--extrusion-head-kit-installation-02.png)

- 按图示进行组装；
- 步骤④：CAB 扩展板需要安装在 5015 风扇后面；
- 步骤⑤：CAN 扩展板需要连接到 CAN 板引脚；
- 结合参考接线图完成组装；

  ![](/images/venture-xl-assembly-guide-extrusion-head-assembly--extrusion-head-kit-installation-03.png)
