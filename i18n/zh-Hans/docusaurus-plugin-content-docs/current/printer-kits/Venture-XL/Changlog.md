# 已知问题

1. 电机连接线使用说明：
    Z0 和 Z3 电机需要使用 3.5m 连接线，Z1 电机使用 1.85m 连接线，并且 Z2 电机和 B 电机的连接线需要对调，以解决 B 电机连接线过短的问题。A 电机连接线保持不变
