## 下图展示了交流电的连接示意图


:::note 注意

由于 Venture XL 的电流相对较大，为了使机器更安全，我们使用交流接触器作为主电源开关。它在动作时会发出“咔哒”声。请不要惊慌，这是正常现象。

:::
