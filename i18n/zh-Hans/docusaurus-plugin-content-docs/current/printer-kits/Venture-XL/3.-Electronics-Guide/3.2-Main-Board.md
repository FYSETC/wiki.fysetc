下图展示了连接到主板的接线。


:::warning 接线

**请注意接线位置和颜色顺序。风扇和 RGB LED 等部分部件出厂时已预先接好线，但可能需要重新排序，才能为 Venture XL 实现正确的引脚定义**

:::



:::note 注意

Venture XL 默认使用 USB 转 CAN 桥接模式，连接器标记为 **MCU-CAN**，在系统中标识为 can2。并且必须在 spider pro 上安装 120R 跳线帽。

K7_Panel 还提供两个基于 RK3568 的 CANBSU 接口，一个位于 K7_Panel 板上，另一个通过灰色线缆连接到 Spider_Pro，标记为 **HOST_CAN**，在系统中标识为 can1。

:::
