# 简介

Venture XL 是一款 600mm³ 的 CoreXY 打印机套件，灵感源自经典的 VORON V2.4。该套件的关键部件为高精度 CNC 加工零件，展现出卓越的品质。同时，它贴心地配备了必要的打印组件和工具，打印头和控制盒已预先组装，让您无需准备额外零件即可轻松开始安装过程。安装完成后，您便可立即投入打印工作，享受高效便捷的打印体验。

它搭载了 550MHz 的 H723 单片机、4 核 2.0GHz 的 RK3568、2GB + 32GB 的上位机、TMC5160 高性能步进电机驱动器以及 7 英寸高清电容触摸屏。打印速度高达 500mm/s，加速度达 50000，不仅带来极速的打印体验，还为您营造舒适的操控感受。

机器框架的尺寸设计预留了 IDEX 和 AWD 的安装空间，为您提供了广阔的升级和改装可能性，可玩性极高。无论您追求更高性能还是个性化定制，都能在这里找到满足。

此外，完整的封闭式设计为打印机提供了保温空间，有效维持打印环境的稳定性。同时，它还具备强大的空气净化能力，可支持多种耗材的打印，更重要的是，能最大程度地降低塑料颗粒对您健康的潜在威胁，为您营造安全舒适的打印环境。

# 特性



## 电子部分：

- RK3568（2+32GB）4 核 A55 2.0GHz 上位机
- Spider Pro 2.0 控制板，550Hz H723
- SB Comobo V2 控制板（通过 CANBUS）
- 7 英寸 FHD 光学贴合电容触摸屏
- RGB 灯光系统，水平 RGB 灯（84 颗 LED）& SB LOGO RGB（10 颗 LED）& 垂直 RGB 灯（2x84 颗 LED）
- 双 350W 电源，48V+24V
- BIG5160+TMC2209 步进电机驱动器
- 大功率 63A/40A 接触器
- 四区独立控制热床
- 预组装的独立控制盒
- 4xZ 减速电机
- 2.5A 高温高扭矩 XY 电机
- Cartographer 3D 电涡流传感器
- 断料传感器
- 罗技 C270 摄像头



## 机械部分：

- 超大尺寸：900x900x900mm，可满足 AWD 或 IDEX 升级改装；

- 封闭腔体，可打印更多材料，打印方式更健康，箱体采用分段组装密封，易于安装并确保结构强度；

- 兼容 Nevermore StealthMax 空气过滤器，箱体密封时保证箱内空气质量无污染；

- 4040 铝型材框架，轻质高强；

- CNC 精密加工的独立四区打印平台，可根据平整度进行微调；

- 拖链系统；

- 12mm 直线导轨，9mm 超耐磨皮带；

- 铝合金外置电控盒，可任意放置（左/右/后），连接线路；

- CNC 铝合金连接组件，确保设备结构强度；

- Z 轴 27:1 减速电机，确保 Z 轴在机器运行或停止时更稳定、不下滑；

- IDMCNC 金属支架可承受高温挑战并确保稳定性。在高温打印环境中，它不会变形或失效，确保长久可靠的性能。支架仅重 26g，比 TAP 调平和老式接近开关更轻。支架仅重 26g，比 TAP 调平和老式接近开关更轻，减少惯性，提升速度、精度和打印质量；

- 可悬挂 5KG 大卷耗材，打印过程中无需频繁更换耗材；

- 40KG 承重福马轮，让设备可随时驻停和运输
