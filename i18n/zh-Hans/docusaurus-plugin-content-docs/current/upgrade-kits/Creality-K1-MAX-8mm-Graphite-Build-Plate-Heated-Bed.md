# Creality K1 MAX 8mm 石墨打印板与加热床

## 产品介绍

适用于 Creality K1 MAX 的升级打印板，实现快速加热和超平整 3D 打印。

#### 购买选项

套装 1：1x 石墨板

套装 2：1x 硅胶加热垫 + 1x 1.5mm 贴纸

## 加热垫安装

:::warning 对齐

加热垫和打印表面贴纸必须方向正确，以确保安装孔与石墨床上的孔对齐。

:::


在尝试安装之前，请确保石墨床已彻底清洁，去除任何油污、灰尘和杂质。

从一个边缘开始，只揭下部分背纸。一边左右移动，一边缓慢按压加热垫表面。然后逐渐在整个床面上操作，边揭背纸边施加均匀压力。

之后应让胶水固化至少 24 小时。

## 打印表面安装


:::note 提示

您可能会发现在安装期间加热床有助于粘附。

:::


在尝试安装之前，请确保石墨床已彻底清洁，去除任何油污、灰尘和杂质。

从一个边缘开始，只揭下部分背纸。一边左右移动，一边缓慢按压贴纸表面。然后逐渐在整个床面上操作，边揭背纸边施加均匀压力。

如果您是在床体开启状态下安装的，之后应关闭加热，并让胶水固化至少 24 小时。
