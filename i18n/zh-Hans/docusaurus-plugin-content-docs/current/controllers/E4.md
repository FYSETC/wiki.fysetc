## 产品介绍


![E4正面2](/images/E4%E6%AD%A3%E9%9D%A22.png)

E4 主板是一款基于乐鑫（ESPRESSIF）ESP32 微控制器的最小化 3D 打印机控制板，内置 Wi-Fi 和蓝牙。控制器速度高达 240MHz，16M flash。

## 特点

- 紧凑尺寸：90mm x 67mm
- 原生支持 Wi-Fi
- 12V 至 24V 输入电源，3 路电源输出和 3 路 5V 输出
- 4 个 **TMC2209** 步进驱动：X、Y、Z 和 E 轴
- 板载 TF 卡座
- CH340 用于高速 USB 串口连接
- X、Y、Z 最小限位开关；同时支持无传感器归零
- 允许使用 Z 轴探针，例如电感式传感器，运行于输入电源电压（12V 至 24V）或 5V
- 一个可控风扇，可选择电源电压（12/24V）或 5V 电压为其供电
- Xh2.54 连接器，牢固且易于插拔
- PCB：
  - 黑色哑光油墨，无铅喷锡工艺
  - 高质量、耐高温 FR4-TG130 PCB

## 为什么需要这块主板？

如果您希望能够通过网页浏览器控制您的 3D 打印机，而无需额外购买树莓派等组件来运行 Octoprint，那么这块主板就是为您准备的。如果您经营打印农场，并希望能够通过 Wi-Fi 远程启动打印，那么这块主板就是为您准备的。

### 原生支持 Wi-Fi

FYSETC E4 基于 ESP32 微控制器，因此 E4 支持 802.11 b/g/n 协议，并且可以在主板上使用 Marlin 固件的自定义分支，从而允许通过网页浏览器控制主板。

这消除了大多数其他主板所使用的传统 LCD 控制器的需求。也无需连接树莓派即可通过 Web 界面控制打印机。Web 界面是流行的 ESP3D webUI，它原生运行于自定义 Marlin 分支上。然后可以通过任何网页浏览器控制打印机，无论是 PC、智能手机还是平板电脑。

例如，您可以在 PC 上使用切片软件对 3D 模型进行切片，然后使用 PC 的网页浏览器连接到打印机，通过 Wi-Fi 将切片后的 GCODE 文件发送到打印机。然后，使用同一个网页浏览器，您可以让打印机开始打印。

### Trinamic 步进驱动

FYSETC E4 使用最新、最好的步进驱动：TMC2209。

1. 超静音
2. 良好的散热
3. 最大电流高达 2A
4. 大散热片，散热良好
5. 支持无传感器归零功能。

### 探针高压供电

使用电感式或电容式探针时的一个常见问题是它们所供电的电压。这些探针通常连接到 Z 限位开关，而 Z 限位开关直接由微控制器供电。这意味着 5V 或 3.3V，但这些探针并非为如此低的电压而设计。相反，它们通常设计为在 6V 或更高电压下工作。使用较低电压操作此类探针会降低其检测距离，从而降低其有效性。

FYSETC E4 为这类 Z 探针提供了专用连接器，使用电源电压为探针供电。如果您使用 12V 电源，探针将运行在 12V 下，使用 24V 电源时则反之。这允许探针在其规格范围内工作，提供最佳的检测距离。

### 板载或外置天线


E4 主板有两个版本。一个是 WiFi 模块的天线为板载。另一个是带有外置天线的 WiFi 模块。此选项为您提供选择：如果您想将主板安装在封闭盒中，外置天线可以避免在密闭空间中 WIFI 信号减弱的问题。

## 固件

出厂固件已刷入自定义 Marlin 分支以及 Web 界面。您可以在我们的 [github](https://github.com/FYSETC/FYSETC-E4) 中获取。您始终需要根据您的机器配置进行修改。您可以按照我们的[视频](https://youtu.be/Skz7xW8TiHI)或以下步骤操作：

1. 为 FYSETC E4 通电，然后将您的 PC、智能手机或平板电脑连接到 SSID "MARLIN_ESP"（默认密码为 "12345678"）。
2. 连接后，打开网页浏览器，访问 "[http://192.168.0.1/](http://www.google.com/url?q=http%3A%2F%2F192.168.0.1%2F&sa=D&sntz=1&usg=AFQjCNHmcUXoQvvfhtmwWsGrZOfa2vJB6A)"，将加载 ESP3D Web 界面。
3. 转到 "ESP3D" 选项卡，输入您的 WiFi 设置（SSID 和密码）。
4. 重置 FYSETC E4。它现在应该连接到您的路由器。
5. 使用 115200 波特率将 USB 线缆连接到 E4 和您的 PC，并发送串口命令 "[ESP111]" 以获取 E4 的 IP 地址。
6. 使用您的网页浏览器访问您刚刚获取的 IP 地址以访问 Web 界面。
7. 您现在可以更新固件。从[此处](https://www.google.com/url?q=https%3A%2F%2Fgithub.com%2Fluc-github%2FMarlin&sa=D&sntz=1&usg=AFQjCNEQnBO_J_SpoZIerKJqDDx-Hts2Og)下载自定义分支，编辑 Configuration.h 和 Configuration_adv.h 以满足您的需求，然后编译。在 PlatformIO 中，您可以将 "upload_port = 您的 E4 的 IP 地址" 添加到您的 platformio.ini 文件中以允许 OTA 更新。或者，在固件编译完成后，使用 Web 界面，转到 "ESP3D" 选项卡，那里有一个固件更新选项，允许上传 firmware.bin 文件。
