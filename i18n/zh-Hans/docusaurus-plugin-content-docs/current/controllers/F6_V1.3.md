## 产品介绍


![F6V1.3](/images/F6V1.3.jpg)

FYSETC F6 主板是一款功能丰富的 3D 打印机及其他 CNC 设备一体化电子解决方案。它提供六个驱动插槽，支持 Pololu 引脚兼容的步进驱动器，尤其是 TMC 驱动模块。使用 TMC2100、TMC2130 和 TMC2208 时无需飞线，并且可以使用 SPI、Usart 及其他引脚配置功能。

## 特性

- 紧凑尺寸：117mm x 87mm
- 完全集成的一体化解决方案：
  - 兼容 Arduino 2560-R3（开箱即用，支持 Sprinter、Repetier-Firmware、Marlin）
  - CH340 用于高速 USB 串口连接
- 通用电源：
  - 可用于电机/热床的 9V-28V 电源
  - 集成高精度电源稳压器（DC/DC）：5V 最大 3A
  - ATmega/逻辑电源输入自动选择（独立供电或来自 USB 供电）
- 便捷的显示屏 + SD 卡连接器：
  - 板载兼容 RepRapDiscount SmartController 的排针
  - **10P FPC 用于串口触摸显示屏**
  - 2X4 排针输出用于 SD 卡模块
- **最多 6 个电机驱动器，支持简便的微步设置，并支持 TMC 驱动器而无需飞线**
- 10 路 PWM 功率 MOSFET 输出（1 路用于热床，3 路用于热端，3 路用于风扇，3 路用于 RGB LED 灯带）
- 热床设计为独立电源输入，以实现最大电流
- 所有未使用的引脚均通过排针引出
- <font color=#0099ff size=3 face="~~板载外部 2Mb SPI Flash~~">~~板载外部 2Mb SPI Flash~~</font>
- PCB：
  - 4 层
  - 内层 2OZ 铜，外层 1OZ
  - 高质量、高温 FR4-TG130 PCB
  - 沉金工艺

## 应用

- 3D 打印机
- CNC 设备
- 其他类似机器

## 不同驱动器的跳线


为了支持尽可能多的不同驱动器，F6 设置了许多跳线位置。不同的驱动模块需要不同的跳线。以下是详细说明：

![F6V1.3-driver-SCH](/images/F6V1.3-driver-SCH.png)

如上原理图所示，驱动部分有三组跳线：JP1、JP6 和 JP8。不同驱动器的对应关系如下表所示：

| 驱动器类别                   | 使用的跳线                          |
| :----------------------------: | :-----------------------------------: |
| A4988/DRV8825/THB6128/LV8729 | JP6（仅 ABC 方式）                  |
| TMC2100                      | JP6（仅 AB 方式）                   |
| TMC2208                      | JP1（短接 2&3）& JP6                |
| TMC2130                      | JP1（短接 1&2）& JP8（全部短接）    |

#### 1- A4988 及类似系列

![F6_4988](/images/F6_4988.png)

如果使用普通的 A4988 系列模块，只需按照上图所示位置设置跳线，绿色阴影部分不应插入任何跳线。

#### 2-TMC2100

![F6_2100](/images/F6_2100.png)

如果使用 TMC2100 模块并希望更改其微步和模式设置，首先必须确保 2100 模块的 CFG1 和 CFG2 通过旁边的引脚连接。（对于 FYSETC 版本，只能在板上进行焊接配置。默认情况下 CFG1 和 CFG2 未连接到排针，已连接的版本稍后将会销售）

#### 3-TMC2208

![F6_2208](/images/F6_2208.png)

如果使用 TMC2208，有两种模式可供选择。FYSETC 的 2208 出厂默认为独立模式。在此模式下，只能通过 MS1 和 MS2 设置微步。
如果需要更多配置，需要启用 PDN。首先，必须短接 PDN 引脚旁的跳线；其次，确保 F6 板上驱动位置旁的 JP1 跳线的 2 和 3 引脚连接；然后，就可以使用 Marlin（SoftwareSerial）对 2208 进行配置。

#### 4-TMC2130

![F6_2130](/images/F6_2130.png)

如果使用 TMC2130，应使用 SPI 模式。FYSETC 有专门针对 F6 的版本。主板上的跳线设置如上图所示，绿色阴影部分不使用。如果想使用 2130 的无传感器限位功能，还需要连接限位开关插座旁的跳线。每个开关的对应位置为：X- = X，X+ = E2，Y- = Y，Y+ = E1，Z- = Z，Z+ = E0，然后配置固件，即可使用 2130 的所有功能。

## 操作指南


#### 步骤 1：USB 驱动

F6 使用了一款廉价但稳定的 USB 转串口芯片 CH340，驱动下载地址：[https://github.com/FYSETC/CH340-Driver](https://github.com/FYSETC/CH340-Driver)

#### 步骤 2：FYSETC Arduino 插件

* 现在无需手动安装 FYSETC 附加组件，可以从 Arduino 板管理器安装。从 Arduino 文件菜单中选择首选项。

![F6V1.3-GUI1](/images/F6V1.3-GUI1.png)

* 将以下 URL 添加到“附加开发板管理器网址”部分。


:::info

https://raw.githubusercontent.com/FYSETC/ArduinoAddons/master/package_fysetc_index.json

:::


![F6V1.3-GUI2](/images/F6V1.3-GUI2.png)

* 打开“开发板管理器”。

![F6V1.3-GUI3](/images/F6V1.3-GUI3.png)

* 搜索“FYSETC_F6”

![F6V1.3-GUI4](/images/F6V1.3-GUI4.png)

如果想使用 F6 V1.4，需要将附加组件更新到 1.4.0

![image-20200112164039226](/images/F6V1.4.png)

* 然后安装它。

![F6V1.3-GUI5](/images/F6V1.3-GUI5.png)

#### 步骤 3：配置固件

* 在 configuration.h 中更改主板类型配置

  F6 V1.3：BOARD_FYSETC_F6_13

  F6 V1.4：BOARD_FYSETC_F6_14

![F6V1.3-GUI9](/images/F6V1.3-GUI9.png)

#### 步骤 4：安装 TMC2130/TMC2208 库

如果想使用 1.1.x 版本固件，并且想使用 TMC2130/TMC2208 驱动器，需要安装 TMC2130/TMC2208 库。

点击“管理库”。

![1574739668740](/images/F6-ManageLib.png)

输入“TMC”并按回车搜索 teemuatlut 的 TMC2130/TMC2208 库。点击“安装”按钮安装该库。

![1574739717005](/images/F6-TMCLib-Search.png)

#### 步骤 5：安装 TMC 库

如果想使用 2.0.x 版本固件，并且想使用 TMC 步进驱动器，需要安装 TMCStepper 库。

点击“管理库”。

![1574739668740](/images/F6-ManageLib.png)

输入“TMCStepper”并按回车搜索 teemuatlut 的 TMCStepper 库。如果尚未安装，点击“安装”按钮安装该库。

![TMCStepperDriver](/images/F6-TMCStepperDriver.png)

#### 步骤 6：连接 USB 线缆

用 USB 线缆连接计算机和机器。然后点击工具->端口并选择 COM 端口。

![F6V1.4-GUI6](/images/F6-ConnectUSB.png)

#### 步骤 7：上传

点击箭头按钮进行上传。

![F6V1.4-GUI7](/images/F6V1.4-GUI7.png)
