# HV5160

![带散热片的 HV5160](/images/HV5160%20with%20heatsink.png)

## 1. 简介

HV5160 专为高压驱动需求而设计，可在 8-60V 电压范围内工作，例如 48V。该设计基于 TMC5160-WA，并使用三星电子的 100V X7R 陶瓷电容

## 2. 特性

- 1000 x 600mil / 25.4 x 15.24mm
- 6 层 TG155 PCB
- 8-60V 3.0A (rms) / 4.2A (峰值)
- 4x DMT6018 (17 mΩ)
- 默认 Step/Dir 接口 & SPI 模式
- 兼容 Stepstick 引脚
- 编码器接口引脚
- 用于无传感器归零的 DIAG 输出
- 配备 393.6 W/(m·K) 铜散热片

## 3. 应用

3D 打印机、CNC、雕刻机或其他类似带步进电机的设备。

### 5.2 配置说明


:::warning

如果您使用 48V 为模块的 VMOT 供电，并使用 24V 降压为 VIO 供电，请确保 48V 和 24V 同时开启（即 VMOT 和 VIO 同时到达）。否则，驱动模块可能会烧毁。

:::
