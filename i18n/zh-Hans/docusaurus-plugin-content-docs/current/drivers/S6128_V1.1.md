## 产品介绍


![s6128](/images/s6128.jpg)

SureStepr SD6128 是一款基于 THB6128 芯片的步进驱动板。它使用简单，通过索引器（DIR/STEP）接口操作即可驱动步进电机。SD6128 可直接替换 Pololu 风格封装的驱动器，包括 SD8825、A4988、A4983 和 Stepsticks。SD6128 的一个显著特点是散热焊盘位于芯片顶部。这使得散热更加容易，并且不依赖本就很小的 PCB 面积来散热。

## 特性


- 采用 4 层 RoHS PCB 制造
- 1、1/2、1/4、1/8、1/16、1/32、1/64 和 1/128 微步进
- 峰值驱动电流高达 2.2A
- 顶部安装散热焊盘
- 更大的散热器安装面积
- 易于使用的 DIR/Step 接口
- 提供衰减（Decay）和外部 Vref 输出引脚
- 驱动芯片：THB6128，具有过流和过温保护
- 电机供电电流：最大 2.2A
- 电机电压：最大 35V

### 电机电流设置

可通过测量 VREF 并旋转微调电位器来调整电流限制（见图 1）。将电压表的正极（+）连接到 VREF，负极（[-]）连接到 GND，然后读取数值。SD6128 使用 0.10 欧姆的电流检测电阻，因此电流限制可按下式计算：
电流限制 = VREF x 2


:::warning

请勿超过电机的额定电流。

:::

## 注意事项



:::warning

<font color="red">本模块为敏感器件，请勿在没有散热器的情况下使用！！！</font>

:::


- 静电敏感——请小心处理，仅在准备安装时才从包装中取出。
- 插入前请检查安装方向。插入不当会损坏驱动器，也可能损坏主控制器。
- 连接/断开电机时请关闭电源，主板通电时请勿插入驱动器。
- 芯片、散热焊盘和散热器可能会变得非常烫，运行时请避免触摸。
- 使用导热胶垫安装散热器，确保其不会接触引脚或板上任何其他导电部件。
