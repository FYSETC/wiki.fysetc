## 1. 简介

QHV5160是HV5160的升级版，专为高压驱动需求而设计，可在8-60V电压范围内工作，例如48V。新设计采用TMC5160的QFP封装，并选用八颗3x3低阻值MOSFET，同时使用三星电子的100V X7R陶瓷电容。

**TMC5160提供三种基本工作模式：**

**模式1：全功能运动控制器与驱动器**
所有步进电机逻辑完全位于TMC5160内部。无需软件即可控制电机——只需提供目标位置。将SD_MODE引脚拉低即可启用此模式。

**模式2：步进与方向驱动器**
外部高性能S曲线运动控制器（如TMC4361）或中央CPU生成与其他组件（如系统中的额外电机）同步的步进与方向信号。TMC5160负责智能电流和模式控制，并提供电机状态反馈。MicroPlyer自动平滑运动。将SD_MODE拉高。

**模式3：简单步进与方向驱动器**
TMC5160根据步进与方向信号定位电机。MicroPlyer自动平滑运动。无需CPU交互；通过硬件引脚进行配置。TMC5160可进行基本的待机电流控制。可选的反馈信号允许错误检测和同步。将SPI_MODE引脚拉低、SD_MODE拉高即可启用此模式。

## 2. 特性

- 900 x 600mil / 22.3 x 15.24mm
- 6层TG155 PCB
- 8-60V 3.0A（有效值）/ 4.2A（峰值）【受连接器限制，而非元件限制。】
- 8 x NMOS（4.4 mΩ）
- 默认Step/Dir接口与SPI模式
- 兼容Stepstick引脚
- 编码器接口引脚定义
- DIAG输出用于无传感器归位
- 配备导热硅胶和超强铝制散热片。

## 3. 应用

3D打印机、CNC、雕刻机或其他类似带步进电机的设备。

### 5.2 配置说明


:::warning ⚠️ 警告

如果您使用48V为模块的VMOT供电，并使用24V降压为VIO供电，请确保48V和24V同时开启（即VMOT和VIO同时到达）。否则，驱动模块可能会烧毁。

:::


#### 5.2.1 焊接跳线

QHV5160的工作模式选择取决于Pin21和Pin22的电平（集成下拉电阻）。

在V1.0E之前的版本中，Pin21固定为高电平并连接到VCC_IO，因此工作模式仅由Pin22决定。

Pin22位于下方JP1接口中间的pad2上。默认情况下，它与pad1相连，因此根据下图，默认工作模式为SPI模式。如果您想切换到独立模式，需要用刀切断pad1和pad2之间的连线（不易看到，在阻焊层下方），然后连接pad2和pad3（焊接）。

---

在V1.0E中，Pin21设置了跳线焊盘，默认为高电平并连接到VCC_IO。可通过操作切换为低电平，即连接到GND。目的是方便一些客户启用内部斜坡发生器。

JP2用于设置SPI_MODE。默认连接为高电平。切断后为低电平，因为该引脚有下拉电阻。
JP1用于设置SD_MODE。默认连接为VCC_IO，即高电平。您可以用刀切断现有连接以将SD_MODE设置为低电平。

## 6. 固件指南

根据硬件指南第5.2节设置工作模式后，您需要进行固件配置。按照以下说明进行Marlin和Klipper固件的不同配置。

### 6.1 Marlin固件

### SPI模式

```
#define *_DRIVER_TYPE  TMC5160
```

#### 独立模式

```
#define *_DRIVER_TYPE  TMC5160_STANDALONE
```

### 6.2 Klipper固件

以Spider2.x为例，在配置文件`printer.cfg`中添加内容。

#### SPI模式

```
##  Make sure to update below for your relevant driver (5160)
[tmc5160 stepper_x]
cs_pin: PE7
# Soft SPI
spi_software_mosi_pin: PE14
spi_software_miso_pin: PE13
spi_software_sclk_pin: PE12
interpolate: True
sense_resistor: 0.075
#diag0_pin: PB14 # For QHV5160 V1.x
diag1_pin: PB14 # For QHV5160 V2.0
run_current: 1.0
#hold_current: 0.5
#stealthchop_threshold: 0

##  Make sure to update below for your relevant driver (5160)
[tmc5160 stepper_y]
cs_pin: PE15
# Soft SPI
spi_software_mosi_pin: PE14
spi_software_miso_pin: PE13
spi_software_sclk_pin: PE12
interpolate: True
sense_resistor: 0.075
#diag0_pin: PB13   # For QHV5160 V1.x
diag1_pin: PB13   # For QHV5160 V2.0
run_current: 1.0
#hold_current: 0.5
#stealthchop_threshold: 0
```

#### 独立模式
只需删除您为SPI模式添加的内容。

### 6.3 通过UART或SPI使用运动控制器

集成的32位运动控制器自动驱动电机到目标位置或加速到目标速度。所有运动参数均可实时更改。运动控制器立即重新计算。最小配置数据集包括加速和减速值以及最大运动速度。还支持启动和停止速度以及第二组加速和减速设置。集成的运动控制器支持对机械参考开关和无传感器失速检测StallGuard2的即时响应。
**优势包括：**
- 灵活的斜坡编程
- 高效利用电机扭矩进行加速和减速，提高机器吞吐量
- 对停止和失速条件的即时响应


:::note 💡注意

Marlin和Klipper目前不支持此模式。更多信息请参考TMC5160数据手册和[ADI GitHub仓库](https://github.com/analogdevicesinc/TMC-API)。

:::
