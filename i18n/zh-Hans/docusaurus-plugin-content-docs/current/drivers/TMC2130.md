## 产品介绍


![TMC2130](/images/TMC2130.jpg)

TMC2130 为 3D 打印、相机、扫描仪及其他自动化设备应用提供集成的电机驱动解决方案。该器件集成了微步进索引器、无传感器堵转检测技术 StallGuard2™、无传感器负载相关电流控制 CoolStep™ 以及完全无噪声的电流控制模式 StealthChop™，旨在驱动双极步进电机。

## 版本差异


版本|差异
:---:          |---
V1.0        |默认为独立模式，如果需要 SPI 模式，必须自行配置。
V1.1        |SPI 模式，SPI 引脚引出（顶部），必须将导线连接到您的板子，并为其配置固件，否则步进电机无法运行。
V1.2        |SPI 模式，SPI&DIAG 引脚引出（底部），用于 F6。

## 特性


- SPI 配置接口（最高 4MHz）
- 最高 256 原生微步（无插值）
- 降低 75% 的能耗
- 高精度无传感器电机负载检测
- 高负载驱动不会失步
- 根据速度自动切换 stealthChop 和 spreadCycle
- 硬件兼容 StepStick 和 Pololu A4988 步进驱动器
- 元件位于 PCB 底部以获得更好的散热
- 自动待机电流降低
- stealthChop - 实现安静运行和平滑运动
- spreadCycle - 高动态电机控制斩波器

## 接口资源

### SPI 模式

#### v1.0

FYSETC v1.0 驱动器出厂预配置为独立模式。要在 SPI 模式下运行，您需要修改驱动器 PCB 上的三个焊桥。

某些版本的 FYSETC v1.0 驱动器在芯片左侧带有焊桥，某些则带有桥接电阻。需要断开此连接才能使 SPI 连接正常工作。两个较小的焊桥需要按图示进行配置。

### 电机电流设置

![TMC2130-current-setting](/images/TMC2130-current-setting.png)

设置电机电流的最佳方法是测量 Vref 引脚上的电压（0…2.5V），并通过电位器调节电压。可设置的最大电机电流为 1.77A RMS（0.11Ohm 采样电阻），但 SilentStepSticks 最高只能使用 1.2A RMS。       
Irms = (Vref * 1.77A) / 2.5V = Vref * 0.71  
Vref = (Irms * 2.5V) / 1.77A = Irms * 1.41 = Imax  
Vref -> Vref 引脚上的电压  
Irms -> 每相 RMS（均方根）电流（Irms = Imax / 1.41）  
Imax -> 每相最大电流（Imax = Irms * 1.41）  


:::note

​    1.Vref 测量 GND 和电位器中间的电压。  
​    2.测量电压时不要连接电机，否则容易烧毁驱动器。  
​    3.测量电压时应接通电源，不要只连接 USB 电源。  
​    4.<font color="red">**请特别注意方向！**</font>  

:::
