## 产品介绍


![TMC2100](/images/TMC2100.jpg)

TMC2100 为 3D 打印、相机、扫描仪及其他自动化设备应用提供集成的电机驱动解决方案。该器件具有集成的微步进索引器、完全无噪声的电流控制模式 StealthChop™，旨在驱动双极步进电机。输出驱动模块由低 RDSon 的 N 沟道功率 MOSFET 组成，配置为全 H 桥以驱动电机绕组。TMC2100 每个输出可驱动高达 2.5A 的电流（需配合适当的散热）。TMC2100 设计用于 5~46V 的电源电压。该器件具有步进和方向接口，并可通过数字引脚进行配置。

## 特性


- 硬件兼容 StepStick 和 Pololu A4988 步进驱动器
- 元件位于 PCB 底部，散热更好
- 自动待机电流降低
- stealthChop - 实现安静运行和平滑运动
- spreadCycle - 高动态电机控制斩波器
- 驱动能力高达 1.2A（RMS）连续线圈电流
- 带微步插值的 Step/Dir 接口（最高 256 微步）
- 通过 CFG 引脚配置

### 电机电流设置

![TMC2100-current-setting](/images/TMC2100-current-setting.png)

设置电机电流的最佳方法是测量 Vref 引脚上的电压（0…2.5V），并通过电位器调节电压。可设置的最大电机电流为 1.77A RMS（0.11 欧姆采样电阻），但 SilentStepSticks 只能使用到 1.2A RMS。

Irms = (Vref * 1.77A) / 2.5V = Vref * 0.71

Vref = (Irms * 2.5V) / 1.77A = Irms * 1.41 = Imax

Vref -> Vref 引脚上的电压

Irms -> 每相 RMS（均方根）电流（Irms = Imax / 1.41）

Imax -> 每相最大电流（Imax = Irms * 1.41）


:::note

1. Vref 测量 Gnd 与电位器中间点的电压。  
2. 测量电压时不要连接电机，否则容易烧毁驱动器。  
3. 测量电压时应连接电源，不要只连接 USB 电源。    

:::

## 使用说明


1. 在 Ramps1.4 或 MKS Gen 上使用时，请移除插座下方的三个跳线帽。
2. <font color="red">**注意方向。**</font>
3. 散热片直接贴在 PCB 上。
4. 电机方向与 4988 和 8825 相反。如果要直接替换 4988，请调整固件或调整电机接线。
