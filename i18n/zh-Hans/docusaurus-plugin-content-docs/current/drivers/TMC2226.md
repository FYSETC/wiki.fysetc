## 产品介绍


![TMC2226](/images/TMC2226.jpg)

TMC2226 是一款用于两相步进电机的超静音电机驱动 IC。TRINAMIC 先进的 StealthChop2 斩波器确保无噪声运行、最高效率和最佳电机扭矩。其快速电流调节以及可选与 SpreadCycle 组合，可实现高动态运动。StallGuard 用于无传感器归位。集成的功率 MOSFET 可处理高达 2A RMS 的电机电流，并具备保护和诊断功能，实现稳健可靠的运行。简单易用的 UART 接口开启了调谐和控制选项。将应用调谐存储到 OTP 存储器中。业界最先进的 STEP/DIR 步进电机驱动器系列将设计升级为无噪声且最精确的运行，提供高性价比且极具竞争力的解决方案。

## 特性与优势


- 两相步进电机，线圈电流高达 2.8A（峰值），2A RMS
- STEP/DIR 接口，具有 8、16、32 或 64 微步引脚设置
- 通过 MicroPlyer™ 插值实现平滑运行的 256 微步
- StealthChop2™ 静音电机运行
- SpreadCycle™ 高动态电机控制斩波器
- StallGuard4™ 用于 StealthChop 的负载和失速检测
- CoolStep™ 电流控制，节能高达 75%
- 低 RDSon，低发热 LS 170mΩ 和 HS 170mΩ（典型值在 25°C 时）
- 电压范围 4.75… 29V DC
- 低功耗待机，符合待机能耗法规
- 内部检测电阻选项（无需检测电阻）
- 被动制动、续流和自动断电
- 单线 UART 和 OTP，用于高级配置选项
- 集成脉冲发生器，用于独立运动

:::tip

TMC2208 输出连续电机电流高达 1.4A，峰值电流高达 2A。因此，驱动模块的参考电压不应超过 1V。同时，驱动模块必须散热，否则会影响驱动模块的寿命。

:::


### 电机电流设置

![TMC2226-current-setting](/images/TMC2226-current-setting.jpg)

![2226电流计算](/images/2226%E7%94%B5%E6%B5%81%E8%AE%A1%E7%AE%97.png)

设置电机电流的最佳方法是测量 Vref 引脚上的电压（0…2.5V），并通过电位器调节电压。最大可设置的电机电流为 1.77A RMS（0.11Ω 检测电阻）。
Irms = (Vref * 1.77A) / 2.5V = Vref * 0.71  
Vref = (Irms * 2.5V) / 1.77A = Irms * 1.41 = Imax   
Vref -> Vref 引脚上的电压  
Irms -> 每相 RMS（均方根）电流（Irms = Imax / 1.41）  
Imax -> 每相最大电流（Imax = Irms * 1.41）   


:::note

1. Vref 测量 Gnd 和电位器中间的电压。  
2. 测量电压时不要连接电机，否则容易烧毁驱动器。  
3. 测量电压时应连接电源，不要只连接 USB 电源。  
4. <font color="red">**请特别注意方向！**</font>

:::

## 设置方法


使用 TMC2208 配置器，您可以通过 UART 接口更改设置并编程 Trinamic TMC2226 的 OTP（一次性可编程）存储器。

###  运行程序：
1. 安装 ScriptCommunicator
2. 下载 TMC2208.scez
3. 使用 ScriptCommunicator 启动 TMC2208.scez 文件：ScriptCommunicator TMC2208.scez
4. 选择正确的串口并点击连接
5. 配置器中的修改会直接传输


:::tip

OTP 位只能编程一次。
如果启用 spreadCycle，则 TOFF 不能为 0（空）。

:::
