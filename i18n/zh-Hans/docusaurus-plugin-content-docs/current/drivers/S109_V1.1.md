## 产品介绍

![S109](/images/S109.jpg)

S109 驱动器基于东芝 TB67S109 步进电机驱动芯片设计。它采用四层厚铜沉金 PCB，并经过自动贴片加工。该驱动器使用索引器（DIR / STEP）控制接口。其最大驱动电流可达 4A。它可以驱动 57 步进电机，兼容 Pololu 引脚定义。它可作为 A4988 模块的替代品。

## 特点


- 采用四层厚铜沉金 PCB。
- 允许整步、半步、1/4、1/8、1/16、1/32 步。
- 最大输入电压：50V；最大输出电流：4A（在良好散热条件下）。
- 配备大型散热器，以获得更好的冷却效果。
- 高效电机电流控制（至于先进的动态混合衰减 ADMD，ADMD 技术，其输入电流可以比传统混合衰减模式更紧密地跟踪，因此可以在高速条件下实现高速电机控制。）
- 芯片内置错误检测电路：热关断（TSD）、过流关断（ISD）和上电复位（POR）。

### 电机电流设置

可以通过测量 VREF 和可调电阻来调整电流限制（请查看接线图）。将电压表 + 连接到 VREF，[-] 连接到 GND 并读取数值。
S109 使用 0.10ohm 电流检测电阻，因此电流限制可按如下方式计算：
[电流限制 = VREF x 2]


:::warning

<font color="red">请勿超过电机电流的额定值，否则电机和电机驱动器会过热，甚至损坏。</font>

:::

## 注意事项


- 驱动器对静电敏感，使用过程中请小心。使用时最好拆除包装。
- 请按正确方向将其安装到主板上，以避免损坏驱动器和主板。
- 插拔驱动器时请关闭电源。
- 驱动器工作时会非常热。请远离以避免烫伤。
- 确保散热器不与驱动器引脚或任何其他导电位置接触。


:::warning

请务必安装散热器和风冷。请勿在长时间使用时无冷却运行。

:::
