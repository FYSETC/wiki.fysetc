# 1.产品介绍

S2240驱动模块基于Trinamic新一代芯片TMC2240设计。得益于全新的架构和工艺，其峰值电流可达3.0A，连续电流可达2.1A，可承受高达36V的输入电压。与TMC2209相比，它在驱动能力和速度响应方面有极大提升，并且还增加了一系列保护措施，如过压保护。
该模块采用6层2OZ PCB、全镀铜镀金排针，极大增强了模块的散热效果和载流能力；默认使用SPI接口，也可通过移动电阻进行串口通信。


# 2.特性

- 硬件兼容StepStick和Pololu A4988步进驱动器
- 元件位于PCB底部，散热更好
- 自动待机电流降低
- StealthChop2™静音PWM模式——运行安静、运动平滑
- SpreadCycle——高动态电机控制斩波器
- 驱动能力高达2.1A（RMS）和3.0A（峰值）线圈电流
- Step/Dir接口，支持微步插值（最高256微步）
- 输入微步1-64可选
- 通过CFG引脚配置
- 供电电压4.5-36V

## 5.1 电机电流设置

TMC2210的电流设置方法略有不同，它由CFG2和CFG3以及连接到IREF的电阻值决定。在开始之前，我们需要明确几个关系：

- IRUN：电机旋转时的电流，由CFG2和CFG3以及连接到IREF的电阻值设置。
- IHOLD：电机保持静止时的电流，由CFG6和CFG7设置。
- IPEAK：也称为Imax或满量程电流，驱动芯片提供的峰值电流（正弦波的峰值）
- IRMS：驱动芯片提供的电流有效值（正弦波的有效值，通常约为峰值/1.41）

### 5.1.1 设置满量程电流范围
满量程电流IFS是峰值电流设置。它通过外部参考电阻和两个配置引脚CFG2和CFG3来选择

通过相同参考电阻的引脚可配置三种不同的满量程电流范围，以适应不同尺寸的电机和应用。这是为了获得尽可能最佳的电流控制分辨率。

将参考电阻RREF从IREF连接到GND。结合引脚CFG3和CFG2，满量程电流范围IFS基于外部电阻设置。

以下公式显示了满量程电流IFS与连接到IREF引脚的RREF分流电阻以及配置引脚设置的关系。比例常数KIFS由CFG2和CFG3设置定义。外部电阻RREF的范围可在12kΩ到60kΩ之间。

$$
I_{FS}=K_{IFS}(KV)/R_{REF}(kΩ)
$$

### 5.1.2 设置Rref

基于CFG2/CFG3引脚设置和不同RREF的IFS满量程RMS电流（安培，A RMS）
| RREF(kΩ) | KIFS = 24 |
| -------- | --------- |
| 12       | 1.41      |
| 15       | 1.13      |
| 18       | 0.94      |
| 22       | 0.77      |
| 27       | 0.63      |
| 33       | 0.51      |
| 39       | 0.44      |
| 47       | 0.36      |
| 56       | 0.30      |

**根据模块电路，我们进行如下演示计算：**
Rref：连接到IREF引脚的电阻，由一个12K电阻和一个最大50K可调电阻组成。可调电阻的出厂值一般位于中间位置，即25K，因此默认Rref=37K。
CFG3默认下拉，相当于GND电平，CFG2在未连接外部电平时为高电平，因此默认KIFS=24KV。

$$
I_{FS}=K_{IFS}(KV)/R_{REF}(kΩ)=24(KV)/37(KΩ)=0.65A
$$

# 7.如何在klipper/marlin中配置代码

S2210只需在软件上配置相应的STEP、DIR、EN引脚，无需额外配置。
值得注意的是，软件上的细分参数需要与硬件上的跳线保持一致。

例如，klipper中X轴配置如下：

```c++
[stepper_x]
##	Connected to X-MOT (B Motor)
step_pin: PE11
dir_pin: PE10
enable_pin: !PE9
rotation_distance: 40
microsteps: 8
full_steps_per_rotation:200  #set to 400 for 0.9 degree stepper
endstop_pin: ^PB14
position_min: 0

##--------------------------------------------------------------------
position_endstop: 300
position_max: 300
##--------------------------------------------------------------------
homing_speed: 25   #Max 100
homing_retract_dist: 5
homing_positive_dir: true
```

不再需要诸如[tmc2209 stepper_x]之类的任何配置。
