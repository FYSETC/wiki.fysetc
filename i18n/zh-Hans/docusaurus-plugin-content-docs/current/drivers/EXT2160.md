# EXT2160

![IMG_6070](/images/IMG_6071.jpg)

## 简介

EXT2160 是一款基于 Trinamic TMC2160 芯片设计的高性能驱动器。它可以提供平滑、低噪音的驱动能力，并能实时检测电机运行状态。它具有堵转检测功能，可实现无传感器归零。配合高性能 MOSFET，默认最大峰值电流可达 6.6A，通过更换 Rs，电流可进一步提升至 15A 峰值。

该驱动器可使用简单的脉冲/方向/使能信号进行控制，可在独立模式下工作，也可通过 SPI 控制以实现更智能的应用。所有信号接口均配备高达 3750V 的数字隔离器，以避免高压和定向电动势对控制器造成不可逆的损坏。

该驱动器可用于任何使用步进电机的场合，并附带 StepStick 转接板，便于安装到需要高压大电流驱动的 3D 打印机上。

## 特性

- 基于 TMC2160

- 超小尺寸：96x57x21

- 19-60V 宽电压支持

- 高性能 MOSFET，默认最大峰值电流 6.6A，更换 Rs 可达 15A 峰值（需更改连接方式）

- 独立模式，Step/Dir 接口，带 MicroPlyer™ 细分补偿，支持 256 微步

- 支持 SPI 模式，与 Marlin/Klipper 等固件完美配合

- 高精度无传感器电机负载检测 / 电流控制，节能高达 75% / 安静运行和平滑运动

- 板载 3750V 数字隔离

- 可选 StepStick 转接板，SPI 直驱

- 铝制外壳，兼顾美观与散热

- 2x5 DC3 连接器，包含 SPI 和 S/D

- 1x7 DIP 拨码开关，用于独立模式、电流调节和功能配置

## 安装

用户可使用驱动器散热底座的宽边或窄边进行安装，即方式 A 或方式 B。为获得良好的散热效果，建议使用窄边安装。驱动器的功率器件会产生热量。如果在高输入电压（>24V）和大功率（>5A）条件下连续工作，应扩大有效散热面积或强制冷却。

请勿在没有空气流通或环境温度超过 40°C 的地方使用；

请勿将驱动器安装在潮湿或金属碎屑环境中。

## 接口连接

- 为使驱动器正常工作，需要以下前提条件：
  
  - 建议使用 19-55V 稳压电源，具体根据电机确定。（驱动器的极限电压为 60V，但这并不意味着可以直接使用 60V 电源工作，因为开机或电机工作时电压可能瞬间升高，极易损坏驱动器）
  - 合适的控制信号源，如控制板、PLC 等；
  - 匹配的步进电机。

### 连接电源

- 如果您的电源输出没有保险丝或其他短路限流装置，请在电源和驱动器之间放置一个
  合适规格的快速熔断保险丝（不超过 8A）以保护驱动器和电源，请将保险丝串联在电源
  正极与驱动器的“19-60V”位置之间。
- 将电源正极连接到驱动器的“19-60V”位置，将电源负极连接到驱动器的“PGND”位置。
- 如果您想同时保证高效率和低噪音，驱动器供电电压应至少为电机额定相电压的 5 倍（即电机额定相电压
  × 相电阻）。
- 如果您需要电机具有更好的高速性能，需要提高驱动器供电电压。
- 如果使用稳压电源供电，电源电压不得超过 50V。
- 如果使用非稳压电源，所需电压不应超过 34V。因为非稳压电源的额定电流为满载电流；当负载很轻时，例如电机不转时，实际电压可高达电源额定电压的 1.4 倍。
- 当电机减速时，它像发电机一样将负载的动能转化为电能。部分能量会由驱动器和电机
  耗散。如果您的应用中有大负载高速运行，相当多的动能会转化为电能。通常简单的线性电源
  有大电容来吸收这些能量，而不会对系统造成损坏。开关电源在过压条件下往往会关断，通常
  剩余能量会被送回驱动器，可能损坏驱动器。为防止这种情况，我们建议使用
  所示的 RC880 再生放电钳位器。再生放电钳位器安装在电源和驱动器之间。

### 连接电机

![image-20221114092516668](/images/image-20221114092516668.png)

**直接连接：** 将 B1/B2 连接到电机的一相，将 A1/A2 连接到电机的另一相；

**并联连接方式：** 一般用于要求转速快、扭矩要求不高的场合；

**串联连接方式：** 一般用于扭矩大、转速要求不高的场合。但串联连接方式在使用过程中，通过的电流较大，因此发热量会比一般并联电机更大。（通常步进电机发热温度达到 90 度是正常的）

### 连接 I/O 信号

该驱动器基于 TMC2160 设计，可提供两种工作模式：独立模式和 SPI 模式。一般应用，如 CNC 或类似设备可直接使用独立模式，配置简单。如果在 3D 打印机上使用，建议使用 SPI 模式以获得更智能的驱动方式，如限位开关归零。目前 Klipper 和 Marlin 均可完美支持 TMC2160，具体配置请参考相应的固件说明。

### 独立模式

使用独立模式时，根据驱动器正面的丝印或上图所示，将 DIP 开关向上拨到“standalone Mode”/“STD”位置，然后向驱动器发送正确的信号。信号输入可在 2x5P DC3 插座，或下图所示的 3.81 间距 5P 连接器。与一般光耦隔离驱动器的区别在于，此处必须连接“3.3-5V”和“SGND”为数字
隔离器供电，输入信号应与该电源共地。

![image-20221112172831803](/images/image-20221112172831803.png)

#### STEP 和 DIR 信号

EXT2160 驱动器有 2 个高速输入端口 STEP 和 DIR，数字隔离，可接受 3.3-5VDC 单端信号，最高电压可达 5.5V，信号下降沿有效。
电机运行方向取决于 DIR 电平信号。如果 DIR 信号为低电平，电机将顺时针运行；如果 DIR 悬空或为高电平，电机将逆时针运行。

#### EN 信号

EN 输入使能或禁用驱动器的功率部分。信号输入为数字隔离，可接受 3.3-5VDC 单端信号，信号最高可达 5.5V。当 EN 信号为低电平时，驱动器使能，电机正常运行；当 EN 信号悬空或为高电平时，驱动器功率部分关闭，电机无励磁。

#### 参数设置

使用独立模式时（即 SPI_MODE 引脚连接到 GND 时），在此模式下驱动器作为纯 STEP 和 DIR 驱动器。SPI 和单线关闭。驱动器以 SpreadCycle 模式或 StealthChop 模式运行。所有寄存器参数设置通过 7 位 DIP 开关配置 CFG0-CFG6（默认上拉至 VCC_IO）实现。按下到 ON 表示连接到 GND，不拨动表示 OFF，默认连接到 VCC_IO。具体配置参考如下：

##### 微步设置

CFG0/CFG1：

| CFG1   | CFG0   | 微步设置     |
| ------ | ------ | --------------------- |
| GND    | GND    | 8 微步，MRES*=5 |
| GND    | VCC_IO | 16 微步，MRES=4 |
| VCC_IO | GND    | 32 微步，MRES=3 |
| VCC_IO | VCC_IO | 64 微步，MRES=2 |

MRES：实际微步分辨率，实际细分。无论外部输入脉冲多少细分，内部都会自动计算并插值到 256 细分运行，使步进电机运行平滑安静。

| ------ | ------ | ------ | ------------ | ----- | ------ |
| GND    | GND    | GND    | IRUN=16，     | 2.44  | 3.45   |

| VCC_IO | VCC_IO | VCC_IO | IRUN=31      | 4.6   | 6.6    |

EXT2160 驱动器板载默认 0.05Ω 采样电阻，即可达到最大 Irms=4.7A，Ipeak=6.6A。如果使用独立模式，EXT2160 的 Irms 电流在 2.35-4.7A 之间可调，Ipeak 在 3.3-6.6A 之间可调。

因此，如果您使用 2.35A 以下的电机，必须使用 SPI 模式，否则电流会过大，导致电机烧毁。

如果您需要更小的电流，必须在 SPI 模式下配置，或在独立模式下更改 PCB 上的采样电阻大小。（驱动器 PCB 上的 0.05Ω 采样电阻由两个 0.1Ω 电阻并联组成，可移除其中一个使采样电阻为 0.1Ω，这样在独立模式下，EXT2160 的 Irms 电流在 1.15-2.3A 之间可调，Ipeak 在 1.65-3.3A 之间可调。如果您需要更多电流范围配置，可参考下表更改采样电阻 Rsense，并根据以下公式计算有效电流 Irms。有关电流的更多信息，请参考 TMC2160 规格书第 8 章）
$$
Irms=\frac{0.325}{0.05}×\frac{Irun+1}{32}×\frac{1}{\sqrt2}
$$

##### 斩波模式选择

CFG5：斩波模式选择

| CFG5   | 斩波设置                                                                                                                                                                                                                                                 |
| ------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GND    | SpreadCycle 运行。（TOFF=3）                                                                                                                                                                                                                                 |
| VCC_IO | StealthChop 运行。（GCONF.en_PWM_mode=1）<br/>*使用 StealthChop 开始运动前，务必让电机静止至少 100ms（假设最小 10MHz fCLK）。这将允许电流调节设置初始电机电流。* |

- StealthChop 是电压斩波原理。除了电机机械滚珠轴承产生的噪音外，它特别确保电机在静止和低速运行时绝对安静。与其他电压模式斩波器不同，StealthChop 2 无需配置。上电后，它会在第一次运动时自动学习最佳设置，并在后续运动中进一步优化设置。初始归零过程足以让系统完成 StealthChop 最佳配置。您也可以配置初始参数以加快自学习过程。StealthChop 2 通过对电机速度变化的即时反应，实现高电机动态性能。
  
  对于高动态应用，除 StealthChop 2 外，spreadCycle 也是一个选项。它可通过输入引脚（独立模式）或 SPI 或 UART 接口配置。StealthChop 2 和 spreadCycle 甚至可以结合使用，实现两全其美：StealthChop2 实现无噪音静止、安静平滑性能，spreadCycle 实现高动态、低振动和最高峰值速度。
  
  spreadCycle 是循环斩波模式。它在宽速度和负载范围内提供平滑运行和良好的共振阻尼。SpreadCycle 解决方案集成了快速衰减周期并自动调整，以确保平滑过零。
  
  StealthChop 2 优势：
  
  - 显著提升低成本电机性能
  - 电机运行平滑安静
  - 绝对无待机噪音
  - 减少机械共振，提升扭矩

##### 配置保持电流自动降低

CFG6：保持电流降低配置

| CFG6*  | 斩波设置                                     |
| ------ | --------------------------------------------------- |
| GND    | 不降低保持电流。IHOLD=IRUN / 不开启自动降低     |
| VCC_IO | 降低至 50%。IHOLD=1/2 IRUN / 开启自动降低，等于运行电流的一半 |

当 CFG6 引脚被驱动到与 CFG5 不同的电平时，会消耗显著电流（20mA），因为输出驱动器试图使 CFG6 电平等于 CFG5。因此，需要 0 欧姆电阻来上拉/下拉 CFG6。因此，仅建议在外部 VCC_IO 电源为 3.3V 电平时将 CFG6 设置为不同于 CFG5。

**注意：**
DIAG 输出默认未配置。在切换到独立模式之前，可使用接口激活它们。

### SPI 模式

SPI 接口是与总线时钟同步的位串行接口。总线主设备向总线从设备发送每一位的同时，从设备也向主设备发送另一位。SPI 主设备与 TMC2160 从设备之间的通信始终由发送 40 位命令字和接收 40 位状态字组成。SPI 命令速率通常为每次完整电机运动几个命令。

使用 SPI 模式时，根据驱动器正面的丝印或上图所示，将 DIP 开关向下拨到“SPI Mode”/“SPI”位置，然后向驱动器发送正确的信号。信号输入只能从 2x5P DC3 插座接入，可使用驱动器附带的灰色排线和 SEXT10 转接板直接连接到各种 3D 打印机主板。如果是其他控制板，需要根据接口定义自行接线。与一般光耦隔离驱动器的区别在于，此处必须连接“3.3-5V”和“SGND”为数字隔离器供电，输入信号应与该电源共地。

已知问题：由于使用了隔离器，某些 3.3V 控制器的 SPI 信号无法同时使用。两个或更多 EXT2160、5V 控制器不受影响。
解决方案：

1. 移除板上的隔离器（SOP16 封装，标记为 3741），这将失去隔离功能，其他不受影响；

2. 将 3.3V 信号转换为 5V 电平，需要电平转换模块。

3. 我们将在下一版本中改进此问题，使其完全兼容 3.3V 信号。

## 固件配置

##### Klipper

参考 TMC2130 的配置，如果安装在 spider 板的 x 轴上，配置如下

```
[tmc2130 stepper_x]
# Soft SPI
spi_software_mosi_pin: PE14
spi_software_miso_pin: PE13
spi_software_sclk_pin: PE12
cs_pin: PE7
interpolate: True
# diag1_pin: PB14 
run_current: 0.800
hold_current: 0.500
sense_resistor: 0.05
#stealthchop_threshold: 99999
```

##### Marlin

需要更改 Configuration.h 文件，例如配置 x 轴

```
#define X_DRIVER_TYPE  TMC2160
```

修改 Configuration_adv.h 中的 RSENCE 值

```
#define X_RSENSE          0.05
```
