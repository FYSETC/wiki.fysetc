## 产品介绍

![LV8729](/images/LV8729.png)

LV8729 驱动模块具有 128 细分，是电流小于 1.5A 的 Nema 步进电机的理想选择，可使电机运行平稳、安静且精确。

## 规格参数

型号                                |LV8729
:----:                                     |:----:
尺寸                       | 1.5mm * 2.0mm（与 A4988 和 DRV8825 相同）
最大驱动电流 |1.5A（默认 0.8A）
工作电压            |6V-36V，建议电压为 12V
支持细分      |1, 1/2, 1/4, 1/8, 1/16, 1/32, 1/64, 1/128

### 电机电流设置

![LV8729-current-setting](/images/LV8729-current-setting.jpg)

可通过测量 VREF 和可调电阻来调整电流限制（请查看接线图）。将电压表正极连接到 VREF，负极连接到 GND 并读取数值。
LV8729 使用 0.10 欧姆的电流检测电阻，因此电流限制可按如下方式计算：
[电流限制 = VREF x 2]


:::warning

<font color="red">请勿超过电机的额定电流，否则电机和电机驱动器会过热，甚至损坏。</font>

:::
