## 产品介绍


![TMC2225](/images/TMC2225.png)

TMC2225 与 TMC2208 类似，采用 TSSOP-28 封装，是一款超静音两相步进电机驱动器，连续驱动电流 1.4A，峰值电流 2A，电压范围 4.75V-36V，256 细分。灵活的 microPlyer 插值单元可提供高达 256 细分，即使在脉冲频率有限的系统中也能实现完美的正弦控制；兼容现有的 3D 打印机电子设备，省去了昂贵的重新设计成本。采用标准的 step/dir 接口，易于使用。它可以替代原有的 A4988，发热更低，特别适合 3D 打印市场。

## 特性


- UART 配置接口（9600-500k 波特率）
-  功率管内置驱动电流 1.4A，峰值电流 2A，电压范围 4.75V-36V
- 高达 256 原生微步（无插值）
- CoolStep ™ 电流动态调节技术，可节省 70% 的能量
- stealthChop2 - 比 stealthChop 更快的电机加速/减速
-  dcStep ™、stallGuard2 ™ 堵转检测技术
- 根据速度自动切换 stealthChop 和 spreadCycle
- 硬件兼容 StepStick 和 Pololu A4988 步进驱动器
- 元件位于 PCB 底部，散热更好
- 自动待机电流降低
- SteaClthhop 静音技术
- spreadCycle - 高动态电机控制斩波器

## 接口资源

###  接线图

![TMC2225-wiring](/images/TMC2225_wiring.png)


:::tip

TMC2225 输出连续电机电流高达 1.4A，峰值电流高达 2A。因此，驱动器模块的参考电压不应超过 1V。同时，驱动器模块必须进行散热，否则会影响驱动器模块的寿命。

:::


### 电机电流设置（与 TMC2208 相同）

![TMC2208-current-setting](/images/TMC2208-current-setting.png)

设置电机电流的最佳方法是测量 Vref 引脚上的电压（0…2.5V），并通过电位器调节电压。最大可设置的电机电流为 1.77A RMS（0.11Ohm 采样电阻），但 SilentStepStick 只能使用到 1.2A RMS。  
Irms = (Vref * 1.77A) / 2.5V = Vref * 0.71  
Vref = (Irms * 2.5V) / 1.77A = Irms * 1.41 = Imax   
Vref -> Vref 引脚上的电压  
Irms -> 每相 RMS（均方根）电流（Irms = Imax / 1.41）  
Imax -> 每相最大电流（Imax = Irms * 1.41）   


:::note

1. Vref 测量 Gnd 和电位器中间的电压。  
2. 测量电压时不要连接电机，否则容易烧毁驱动器。  
3. 测量电压时应连接电源，不要只连接 USB 电源。  
4. <font color="red">**请特别注意方向！**</font>

:::

## OTP 设置（参考 TMC2208）


使用 TMC2208 配置器，您可以通过 UART 接口更改设置并编程 Trinamic TMC2208 的 OTP（一次性可编程）存储器。

###  运行程序：
1. 安装 ScriptCommunicator
2. 下载 TMC2208.scez
3. 使用 ScriptCommunicator 启动 TMC2208.scez 文件：ScriptCommunicator TMC2208.scez
4. 选择正确的串口并点击连接
5. 配置器中的修改会直接传输


:::tip

OTP 位只能编程一次。
如果启用 spreadCycle，则 TOFF 不能为 0（空）。

:::


### 硬件连接

![TMC2208-hardware-connection](/images/TMC2208-hardware-connection.png)

您可以使用任何具有 0-5V 逻辑电平的 RS232 串行适配器（例如 FTDI-Breakout），并且 SilentStepStick 测试器/编程器可用作连接适配器。


:::tip

在 TMC2208 SilentStepStick 上，PDN_UART 引脚旁边的跳线必须闭合，以通过排针访问该引脚。

:::



## 固件设置（与 TMC2208 相同）


您不需要设置固件，只需通过 MS2、MS1 将微步设置为固件，通常为 16 微步。

如果您想使用 UART 模式，请确认您的接线正确。

然后，您可以通过固件对驱动器进行一些列配置。
设置步骤如下：

##### 1. 接线

为了方便您，我们对新版本中的所有新 TMC 驱动器进行了调整。我们添加了排针，为可能需要接线（SPI 或 UART）的位置扩展了板子。

对于 UART，我们在板上添加了一个 1K 电阻，直接提供 RX 和 TX，您无需焊接。

对于 F6 或类似板，请忽略上述两点并剪掉扩展排针，它们对您没有用处。直接将其安装在板上，并遵循板的说明。

对于需要接线的板，请参考下图：

![TMC2225_Uart_Mode_Wiring](/images/TMC2225_Uart_Mode_Wiring.png)

##### 2. Configration.h

   删除您需要使用 TMC2225 驱动器的轴前面的“//”，并更改步进驱动器类型，我假设您需要 XY 轴。

   ```c++

    *          TMC2130, TMC2130_STANDALONE, TMC2208, TMC2208_STANDALONE,
    *          TMC26X,  TMC26X_STANDALONE,  TMC2660, TMC2660_STANDALONE,
    *          TMC5130, TMC5130_STANDALONE
    * :['A4988', 'DRV8825', 'LV8729', 'L6470', 'TB6560', 'TB6600', 'TMC2100', 'TMC2130', 'TMC2130_STANDALONE', 'TMC2208', 'TMC2208_STANDALONE', 'TMC26X', 'TMC26X_STANDALONE', 'TMC2660', 'TMC2660_STANDALONE', 'TMC5130', 'TMC5130_STANDALONE']
   ```
