## 简介


![ST820](/images/ST820.png)

ST820 是一款易于使用的驱动板，适用于 3D 打印机、路由器等设备。它为步进电机驱动器提供了一种紧凑的解决方案，所需外部设备极少，且无需额外组件。

该硬件完全兼容 RepRap Arduino Mega Pololu Shield (RAMPS) 或其他类似的熔融长丝制造 (FFF) 3D 打印平台，可作为类似解决方案的快速直接替代品。与大多数其他竞争对手的解决方案不同，ST820 帮助客户真正发挥高微步分辨率工作的优势。

## 板卡概述


该板卡的主要特性如下：
• 供电电压范围为 7 V 至 45 V
• 每个电机相位的输出电流最高可达 1.5 A rms
• 通过微调电位器进行峰值电流调节
• 外形尺寸和连接方式兼容 RAMPS (RepRap Arduino Mega Pololu Shield) 或类似板卡
• 基于 STSPIN820 驱动器，具有以下特性：
      – 步进电机驱动，微步分辨率最高可达 1/256 步
      – 过流、短路和过温保护

## 设置步进模式


输入 MS0、MS1 和 MS2 用于设置 STSPIN820 驱动器的步进模式，如下表所示。

| MS2  | MS1  | MS0  | 步进模式  |
| ---- | ---- | ---- | ---------- |
| 0    | 0    | 0    | 整步  |
| 0    | 0    | 1    | 1/2 步   |
| 0    | 1    | 0    | 1/4 步   |
| 0    | 1    | 1    | 1/8 步   |
| 1    | 0    | 0    | 1/16 步  |
| 1    | 0    | 1    | 1/32 步  |
| 1    | 1    | 0    | 1/128 步 |
| 1    | 1    | 1    | 1/256 步 |

## 调节电机峰值电流

R7 微调电位器用于调节 STSPIN820 PWM 电流控制器的参考电压，从而设置电机相位的峰值电流输入。

R7 微调电位器控制电流水平。顺时针旋转可增大电流水平，逆时针旋转可减小电流水平。

调节范围取决于 VDD 逻辑供电电压（J2 的引脚 6），如下表所示。

| VDD  | 最小值                         | 最大值                              |
| ---- | ------------------------------- | ------------------------------------ |
| 3.3V | VREF   = 0 V   Ipeak   = 0 A(1) | VREF   = 0.67 V   Ipeak   = 4.5 A(2) |
| 5V   | VREF   = 0 V   Ipeak   = 0 A(1) | VREF   = 1 V   Ipeak   = 6.8 A(2)    |

(1) 由于 PWM 电流控制操作，可能存在最小电流

(2) STSPIN820 的过流保护可能会限制实际峰值电流



## 修改峰值电流范围

可通过修改部分板卡组件来调节微调电位器。

具体而言，参与定义峰值电流的组件包括：

• 两个采样电阻

• 上拉电阻 (R6 = 39K)

• 采样电阻 (R8 和 R9 = 0.15R)

详细公式如下：



![ST820_2](/images/ST820_2.png)



更改采样电阻时需要特别注意：

• 两个采样电阻必须具有相同的阻值

• 电阻上的功耗等于 Ipeak2 × Rsense。必须据此选择额定功率。


:::note

<font color="red">**警告！** 板上安装的部分组件在运行期间可能达到危险温度。</font>

使用板卡时，请遵守以下注意事项：

- 请勿触摸组件

- 请勿覆盖板卡

- 请勿使板卡接触易燃材料或受热时释放烟雾的材料

运行结束后，请等待板卡冷却后再触摸。

:::
